## 🌟 Fitur Utama

- **Desain Responsif**: Tampilan optimal di perangkat Mobile, Tablet, dan Desktop.
- **Katalog Produk**: Menampilkan 8 produk unggulan dengan efek *hover* yang mulus.
- **Interaksi Dinamis (JS)**:
  - Menu navigasi mobile (Hamburger Menu).
  - Simulasi tombol "Add to Cart" dengan animasi perubahan ikon.
  - *Cart counter* otomatis pada navbar.
- **Tema Warna Kustom**: Menggunakan palet *Forest Green* dan *Campfire Amber* khas alam bebas.

## 🛠️ Teknologi yang Digunakan

- **HTML5**: Struktur kerangka website.
- **Tailwind CSS (CDN)**: Framework CSS untuk *styling* secara cepat dan responsif.
- **Vanilla JavaScript**: Untuk fungsionalitas interaktif (menu & keranjang).
- **Unsplash API**: Sumber gambar *dummy* berkualitas tinggi.

## 🚀 Cara Menjalankan

Tidak perlu instalasi khusus, cukup ikuti langkah berikut:

1. Salin seluruh kode HTML yang telah dibuat.
2. Simpan dalam file bernama `index.html`.
3. Buka file `index.html` tersebut menggunakan browser apa saja (Chrome, Firefox, Safari, Edge).
4. Pastikan perangkat Anda terhubung ke internet agar Tailwind CSS dan gambar dari Unsplash dapat dimuat.
